## About Me

I'm a Software Engineer with an Electronics and Communication Engineering background, currently building my expertise in Data Engineering, Python, Databricks, SQL, and cloud-based data platforms.

My engineering journey started with Embedded Systems, IoT, and hardware-software integration, where I worked on projects involving ESP32, sensors, GSM/GPS modules, automation, and real-world data collection. This foundation helped me develop a strong understanding of how software interacts with systems, devices, and data.

Today, my focus has shifted toward software and data engineering. I work with Python and SQL and am developing hands-on experience with PySpark and Databricks for data processing and pipeline development. I'm also working with cloud and data-platform technologies such as AWS S3, Lambda, Glue, and SQL Server as part of modern data workflows.

I enjoy understanding systems end-to-end:

<div align="center">

**Data Ingestion → Transformation → Processing → Storage → Analytics**

</div>

I am continuously strengthening my skills in Data Engineering, Cloud Technologies, Distributed Data Processing, Python-based Solutions, and AI/ML — with the goal of building reliable, scalable, and practical engineering solutions.
